# Contributing

## DCO sign-off

All commits submitted in pull requests must carry a Developer Certificate of
Origin sign-off. The DCO pull-request check verifies every commit for a
`Signed-off-by:` line.

Read the [Developer Certificate of Origin](https://github.com/gnuradio/gnuradio4/blob/main/DCO.txt)
in the top-level GNU Radio 4 repository, then use `git commit -s` to add your sign-off:

```text
Signed-off-by: Your Name <you@example.com>
```

A DCO sign-off is not a cryptographic signature.
